FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

No. You can shorten links without an account, but signing up unlocks link management, custom slugs, analytics and QR code tools.

Are the shortened links permanent? Will they expire?

Shortened links are permanent by default and do not expire unless you choose to set an expiry date or delete them.

Are there any limitations on the number of URLs I can shorten?

The Basic plan offers unlimited URL shortening. Paid plans add extra features such as branded domains, advanced analytics and team tools.

Can I customize the shortened URLs to reflect my brand or content?

Yes. You can create custom slugs and connect your own branded domain so every link reflects your brand.

Can I track the performance of my shortened URLs?

Yes. Our analytics show clicks, scans, locations, devices and referrers so you can monitor how each link performs.

How secure is the URL shortening service?

Every link can be scanned against known spam and malware lists. Connections should be encrypted with HTTPS.

What is a QR code and what can it do?

A QR code is a scannable image that opens a link when scanned with a phone camera. Use it on flyers, products, menus and events.

Is there an API available for integrating the URL shortening service?

Yes. API access allows you to create and manage links from your own applications and websites.
